# 학생 패키지 조회 화면 검증 · 2026-10-24

20단계 학생 `renderVulnerabilities`를 구현했다. 제공 scanner·OSV 클라이언트·공통 UI·설정은 보존한다. 패키지 설치/갱신이나 외부 조회 승인 목록 변경은 하지 않았다.

정확한 설치 버전과 lockfileVersion/lockfileHash, 전체·패키지 조회 시각, OSV 출처, 취약점 ID와 수정 시각을 표시한다. 미설정·미조회·lock 확인 불가·일부 실패·알려진 항목 없음을 구분한다. 부분 조회에서 이미 받은 ID를 보존하며 조회 중/취소/오류에는 이전 행을 남기지 않는다.

별도 학습 기록 저장소의 합성 시험은 버전 범위·잘못된 출처·비밀 모양 입력의 거부와 새 해시로 교체를 확인한다. 기본 앱에 조회 프로젝트·승인 목록이 없으면 not_configured 또는 not_checked가 정상이며, 이것을 실제 OSV 성공이나 취약점이 없다는 근거로 쓰지 않는다.
