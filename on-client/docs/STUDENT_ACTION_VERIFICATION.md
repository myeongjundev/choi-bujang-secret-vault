# 학생 조치 화면 검증 · 2026-10-24

19단계의 학생 `renderAction`만 구현했다. 제공 UI·서버·인증·13~18단계 함수는 보존했다.

상태별 원래 코드와 준비·미실행·전송·ACK·관측 효과·거절·실패·기한 만료·결과 불명을 구분한다. succeeded도 effectApplied:true, 관측 시각, 현재 사건에 연결된 접수 정보가 있어야 효과 확인으로 표시한다. 현재 사건·근거·조치·실제 대상·세대·요청·접수·버전·확인 기한을 전달받은 범위에서 표시한다.

확인 티켓·원문 오류·추가 필드는 표시하지 않는다. 학생 함수에 버튼·요청·집행·자동 재시도를 추가하지 않았다. 새 DOM으로 교체해 idle과 다른 사건에서 이전 결과를 남기지 않는다.

별도 학습 기록 저장소의 합성 상태 시험과 기존 회귀를 실행한다. 이 검증은 실제 SDP 계정·집행기·대상·효과 조회가 연결됐다는 뜻이 아니다. 현재 기본 기록에는 지원 조치가 없으며 실제 집행은 기다림(UNV)이다.
