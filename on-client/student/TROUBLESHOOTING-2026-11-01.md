# 제공 서버 수정 제거 · 2026-11-01

현재 포털은 제공 src 서버 파일 수정을 금지한다. 이전 57603a5는 공식 CLI에서 PC 조회를 제공하려고 src/server.mjs에 import·주석·호출 3줄을 추가했다. 기능 시험은 통과했지만 작업 위치 제한과 충돌했다.

## 수정

- src/server.mjs를 보존한 공식 0.2.14 배포 원본으로 복원했다. src/public/tools/vendor 및 package.json 40개 파일은 배포본과 줄바꿈 정규화 비교에서 차이가 없다.
- PC 조회는 기존 학생 run-local-pc.mjs에서 제공 createOnServer와 학생 라우트를 조합한다. 공식 CLI는 학생 PC 라우트를 연결하지 않는다.
- PC 화면의 잘못된 실행 안내를 학생 명령으로 수정했다. START_HERE·README·학생 설명서를 현재 두 실행 경로에 맞췄다.
- 계정·AI 연결은 원래 공식 도구를 다른 포트에서 실행한다. 같은 서버에서 PC와 계정 기능을 동시에 제공하던 변경은 제거했다. 두 서버가 로그인 상태를 공유한다고 주장하지 않는다.

## 검증

Node v24.19.0 Windows에서 학생 55/55 및 이전 단계 88/88, 총 143개 통과. 제공 서버 보존 회귀시험은 수정 전 실패, 수정 후 통과했다. 원본 LF 해시를 기준으로 Git CRLF checkout도 허용한다.

학생 서버 5191에서 실제 PC 7/7, SDP 미연결 분리, 재조회 추이, Enter/Tab으로 재조회·취소, 취소 후 복구를 확인했다. 서버를 종료한 뒤 같은 화면에서 조회 실패·이전 수치 제거를 확인하고 재시작 후 7/7로 복구했다. 정상·오류 화면을 학습 기록 저장소의 evidence/troubleshoot-2026-11-01에 보관했다.

공식 도구는 5190에서 개인 설정 준비 성공·루트 200을 확인했다. 공식 서버의 /student/pc와 /api/student/local-pc는 404다. 이 검증 서버는 종료했다. 실제 사용자 승인·AI 호출은 하지 않았다.

## 실행

on-client 폴더에서 `node student/run-local-pc.mjs` → http://127.0.0.1:5189/student/pc → PC 상태 조회. 정상 조회는 측정 시각과 7개 항목 상태가 보인다. 취소·서버 중단은 확인 불가로 표시되고 이전 숫자가 현재 결과로 남지 않아야 한다.

계정 연결이 필요하면 별도 창에서 `powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1 -Port 5190` → http://127.0.0.1:5190/ . 자세한 Node 선택·대체 포트·종료는 START_HERE를 따른다.

이 문서를 포함한 수정 저장점이 새 제출 후보다. 이전 후보 57603a5와 구분하고, GitHub에 올라간 수정 저장점의 40자리 커밋을 제출한다. 다른 PC/OS·사람의 구두 시연·공식 재접수는 이번 검증에 포함하지 않는다.
