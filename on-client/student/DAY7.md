# 7일차 · 시연 순서와 되는 것·안 되는 것

2026-11-02 기준. 처음 실행은 [START_HERE](START_HERE.md)를 따른다. 아래 "확인한 결과"는 이 PC(Windows·Node 24.19.0)에서 실제로 실행한 결과이며 다른 PC·다른 사람의 결과가 아니다.

## 시연 순서

1. on-client 폴더에서 `node student/run-local-pc.mjs`를 실행하고 http://127.0.0.1:5189/student/pc 를 연다.
2. 조회 전 화면: 숫자가 없고 SDP 미연결이 PC 조회와 따로 표시된다.
3. **PC 상태 조회**: 위 카드 4개(CPU·메모리·디스크·조회 상태)와 측정 시각, 아래 추이와 연결·Windows 기록을 보여 준다.
4. **PC 상태 다시 조회**: 추이 표와 이전 조회 대비 증감을 보여 준다.
5. 다시 조회한 직후 **PC 조회 취소**: 숫자가 지워지고 취소 이유가 나온다.
6. 실행 창에서 Ctrl+C로 서버를 끄고, 페이지를 새로 고치지 말고 화면의 조회 버튼을 누른다. 숫자 없이 확인 불가가 나온다. 같은 명령으로 다시 켜고 조회하면 복구된다.

## 안 되는 것과 확인하지 않은 것

| 항목 | 상태 | 이유 |
| --- | --- | --- |
| 실제 SDP(회사 서버) 연결 | 연결 없음이 정상 | 이번 과정에서 학생 인증서를 발급하지 않는다 |
